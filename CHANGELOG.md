# Changelog

This changelog records supported Android release facts established by repository acceptance records.

## 1.5.0 — versionCode 10

- Added Chord Practice V1 with comprehensive and sequential practice flows.
- Added durable Chord reports, History projection and report detail.
- Added Chord Query Text V1, Natural Major Scale & Key Signature V1, and Interval Query V1.
- Improved MIDI session lifecycle, active-practice preservation, tablet tool presentation and deterministic validation coverage.
- Preserved the production package, permanent signing identity, durable Sight Reading data, and secure user-initiated updater boundary.

## 1.4.0 — versionCode 9

- Added double-note Sight Reading with tested interval allocation and order-independent dyad input.
- Added answer feedback showing the target interval.
- Updated the official Android launcher icon and generated density/adaptive resources.
- Tuned Sight Reading timing: single-note answer deadline remains 5 seconds; double-note answer deadline is 7 seconds, with longer double-note feedback holds.
- Preserved local settings/history compatibility, native Bluetooth MIDI behavior and the secure user-initiated updater boundary.

Earlier private development phases are intentionally not reconstructed as public releases here.
