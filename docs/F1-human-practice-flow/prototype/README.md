# F1 静态原型

完全独立于 production 的 HTML/CSS/JavaScript 原型。它不导入 `src`、不读取或写入练习记录、不连接 MIDI，也不修改任何训练功能。

## 打开方式

直接打开 `index.html`，或从仓库根目录启动任意静态文件服务器后访问：

```text
docs/F1-human-practice-flow/prototype/index.html#home
```

## 6 个 QA 屏幕

- `#home`
- `#score-pre`
- `#score-focus`
- `#result`
- `#fundamentals`
- `#plan`

硬基准：1366 × 768。补充检查：1536 × 864。

主要可点击路径：首页 → 曲谱练习前 → 专注模式 → 结果 → 按建议再练；首页也可进入今日训练和基础练习模板。设置、工具与详细数据按钮会打开静态底部面板。
