# F1 现有控件分级表

## 口径

- 审阅范围：`src/renderer/src/App.tsx`、`data.ts`、现有页面与共用练习组件；另将需求中明确点名的曲谱练习控制台控件列为“需求所述”，避免把尚未出现在当前工作树的页面误写为已实现。
- 一行代表一个具有独立用户意图的主要控件或控件组；分段按钮中的每个选项不重复计行。
- **LEVEL 1**：不展开即可完成本页主任务。
- **LEVEL 2**：放入“练习设置”，按需展开。
- **LEVEL 3**：放入“高级工具/设备诊断/详细数据”，普通练习不占主视野。
- **REMOVE**：从用户信息架构移除；不等于删除底层正式代码。
- “隐藏=是”表示默认不在主视野；“删除=是”只表示未来正式 UI 不提供此独立控件。本 F1 不修改 production。

## 最高优先级的 10 个减负决策

1. 首页从“6 个功能模块”改为“今日训练 + 继续上次”。
2. 训练计划默认只回答今天练什么；阶段/每周/映射/验收进入长期计划。
3. 五大练习共用练习前—专注—结果三段式，不再在一个页面同时配置、练习、监控和报告。
4. 练习中把 6–7 项累计统计降为一个简单进度和一句必要反馈。
5. 虚拟键盘默认隐藏，只有教学或排查时显示。
6. 曲谱练习中的 Tier、MusicXML 校验、参考 MIDI、AI 配置和诊断退出主视野。
7. Wait 模式不显示速度；有速度的模式优先显示实际 BPM。
8. 结果页把 9–20 项指标折叠，首屏先给具体结论和下一步。
9. 以练习状态、样本量、趋势和条件替代“掌握度百分比”。
10. MIDI 测试与判定测试退出普通用户导航，设备异常时才提供诊断入口。
