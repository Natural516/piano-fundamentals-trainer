# F1 文案与术语语言

## 中文语气

- 像冷静、具体、尊重证据的陪练老师，不像评分机器或管理后台。
- 先说用户能做什么，再说系统状态；短句、动词开头。
- 正确反馈不过度庆祝，错误反馈不责备；描述现象，不推断天赋或能力。
- 只在用户确实要排查设备时使用 MIDI、BPM、MusicXML 等专业词。
- 不使用英文眉题装饰主页面；需要英文时放在帮助或技术详情。

## 技术词翻译表

| 内部/当前词 | 用户可见方案 | 使用规则 |
|---|---|---|
| Wait | **弹对后继续** | 模式选择中使用；此模式不显示速度控件 |
| Realtime | **跟随速度** | 需要节拍/时间判定时显示实际 BPM |
| Playback | **跟着示范弹** | 若只是聆听则写“听示范”，不要混用 |
| Teaching Playback | **分段示范** | 放入“高级工具”，不在练习中出现 |
| Tier A / Tier B | 不对用户显示 | 用功能结果命名，如“基础分析 / 细节分析”；能自动选择则不提供选择 |
| Evidence | **练习依据** / **本次记录显示** | 统计详情中可解释来源；不显示解析器名称 |
| Evidence Resolver | 不对用户显示 | 系统自动处理 |
| Mastery | **练习状态** | 使用状态词和证据条件，不主打百分比 |
| Planner / Planner V2 | **今日安排** / **训练计划** | 版本号不对用户显示 |
| ScoreTime | 不对用户显示 | 界面用“小节 / 拍 / 当前播放位置” |
| PracticeRecordV2 | **练习记录** | 版本号不对用户显示 |
| sourceEventId | 不对用户显示 | 仅诊断日志保留 |
| MusicXML | **曲谱文件** | 导入操作可写“导入曲谱”；格式名放在辅助说明 |
| MusicXML validation | **曲谱检查** | 失败时先给可行动建议；校验详情进入高级工具 |
| Reference MIDI | **参考演奏** | 高级工具；若只有文件选择，写“添加参考演奏” |
| AI Coach | **练习建议** | 作为结果页能力出现；独立页保留“AI Coach”仅作为产品名副标题 |
| MIDI device | **电钢琴 / MIDI 键盘** | 状态写“设备已就绪”；设备设置中才显示 MIDI |
| Web MIDI API | 不对普通用户显示 | 只在诊断页显示 |
| BPM | **速度 72 BPM** | BPM 是钢琴用户可接受术语，但必须带实际数值；百分比仅辅助 |
| 80% speed | **速度 72 BPM（原速的 80%）** | 实际 BPM 在前；原速百分比在后 |
| offset | **早了 80 毫秒 / 晚了 80 毫秒** | 详细数据可保留 ms；练习中优先“稍早 / 稍晚” |
| velocity | **力度** | 设备诊断中可补充 MIDI 数值 |
| tolerance | **判定宽松度** | 默认由系统决定；如必须提供，进入高级设置并解释影响 |
| sync warning | **双手没有同时落下** | 描述可观测现象，不展示“同步警告”计数为主反馈 |
| missing note | **漏了一个音** | 若可定位则写具体声部/音名 |
| extra note | **多弹了一个音** | 若可定位则写具体音名 |
| wrong note | **弹错音** | 优先“目标 F♯，弹成 F” |
| early / late | **稍早 / 稍晚** | 结果中可附具体拍点与毫秒 |
| mode | **练习方式** | 不单独写抽象“模式” |
| Grand Staff | **大谱表** | 必要时帮助文案补充 Grand Staff |
| loop | **重复次数** / **循环练习** | 数量写“重复 3 次” |
| count-in | **预备拍** | 直接显示“预备拍 2 / 4” |

## Mastery 状态式表达

主状态只用以下 6 档；状态由系统内部计算，但界面必须同时展示支撑条件。

| 状态 | 适用含义 | 推荐文案示例 |
|---|---|---|
| 未建立足够证据 | 样本过少、条件不可比或近期无记录 | “还需要 2–3 次同条件练习，才能判断变化。” |
| 正在建立 | 已有少量稳定信号，但尚不足以复现 | “在 60 BPM 下开始稳定；原速表现还没有足够记录。” |
| 正在巩固 | 多次练习可见改善，偶尔仍出现集中问题 | “右手单独练习较稳定，合手时第 4 小节仍会停顿。” |
| 基本稳定 | 当前条件下多数近期样本表现一致 | “72 BPM、双手条件下，最近 4 次表现基本稳定。” |
| 稳定 | 多个近期样本、目标条件下可复现 | “原速双手已有 5 次稳定记录；建议间隔复习。” |
| 需要复习 | 近期同条件表现持续下滑或长期未练 | “距上次稳定练习 18 天，建议先用 80% 速度复习。” |

每个状态旁固定展示：

- 样本量：例如“近 14 天 5 次”。
- 近期趋势：改善 / 持平 / 波动 / 暂不可判断。
- 当前条件：曲目片段、手别、实际 BPM、练习方式。
- 原速证据：充足 / 不足 / 尚无。

禁止把“掌握度 87%”作为标题、徽章或主结论。若内部数字必须用于调试，只能在高级诊断中出现。

## 关键页面文案模板

### 首页

- 标题：“下午好，今天先练 20 分钟”
- 主卡：“按这个顺序开始”
- 主按钮：“开始今日训练”
- 继续卡：“上次练到《案例 1》第 1–8 小节”
- MIDI：“设备已就绪 · Yamaha P-125” / “未检测到电钢琴”

### 练习中

- 位置：“第 4 小节 · 第 3 拍”
- 必要反馈：“右手 F♯ 弹成了 F”
- 时机反馈：“这一拍稍晚”
- 暂停状态：“已暂停，准备好后继续”

### 结果

- 最好表现：“第 1–3 小节的节奏保持得很稳定。”
- 主要问题：“第 4 小节右手在第 3 拍连续两次弹错 F♯。”
- 原因：“两次都发生在相同位置，因此比偶发错音更值得先处理。”
- 建议：“先用右手，以 60 BPM 重复第 4 小节 3 次。”
- 主按钮：“按建议再练”
- 证据不足：“本轮只完成 4 个事件，暂不判断整体趋势。”

## 禁止文案模式

| 不使用 | 原因 | 改为 |
|---|---|---|
| “你已经掌握了” | 超出证据边界 | “当前条件下基本稳定” |
| “表现很差” | 责备且不可执行 | “第 4 小节有 3 次相同错音” |
| “82% / 3 errors / timing 76%”作为首屏 | 用户还不知道下一步 | 先解释最好表现、问题与建议，数据折叠 |
| “系统判断失败” | 不告诉用户怎么做 | “没有收到足够的 MIDI 输入，请检查设备连接” |
| “未完成练习不会保存” | 惩罚性且丢失有价值信息 | “结束本轮？已完成部分会保留为一次未完成练习” |
| “保存设置”作为所有抽屉唯一动作 | 许多设置可即时预览 | 明确“应用到本轮”；全局偏好再写“保存” |
