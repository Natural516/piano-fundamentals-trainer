# F1 每页唯一主任务

> 判断规则：如果一个元素不能帮助用户完成本页唯一主任务，它就必须进入按需展开、迁移到其他页面，或退出用户界面。

| 页面 | 唯一主任务（用户语言） | 页面必须让用户完成 | 不应占据主视野 |
|---|---|---|---|
| 首页 | **开始今天最值得练的一项。** | 看懂今日建议、上次进度、MIDI 状态，并用一个按钮开始/继续 | 六大模块等权网格、完整统计、设备测试、计划编辑 |
| 训练计划 | **确认今天按什么顺序练。** | 查看今日任务、预计时长、完成状态；调整顺序/进入任务 | 阶段项目管理、技术映射、六级验收表、周目标编辑同时平铺 |
| 识谱 | **看谱并弹出当前音。** | 看清谱面、开始练习、获得必要正误反馈 | 大量累计指标、虚拟键盘默认展开、题目之外的设置 |
| 节奏 | **按当前节奏型稳定落在拍点上。** | 看清节奏格与当前拍，按实际 BPM 练习 | offset 技术值、判定引擎术语、设备事件 |
| 音阶 | **按选定条件连续弹完这条音阶。** | 看清调性/手别/方向和当前位置，持续练习 | 同时显示 BPM 预设与滑杆、完整音序和键盘争夺主视觉 |
| 和弦 | **弹出当前目标和弦。** | 看清和弦目标，完成一组题或和弦进行 | 输入窗口毫秒数、所有和弦类型与转位常驻 |
| 左右手协调 | **让双手按当前型稳定配合。** | 看清双手格与当前位置，保持同步 | 单独的判定台、冗余当前拍/格/细分统计、虚拟键盘默认展开 |
| 曲谱练习 | **练这一段谱。** | 看清曲名、乐谱和片段；确认最少设置；开始 | MusicXML 管理、参考 MIDI、Teaching Playback、AI 配置、诊断 |
| 练习结果 | **决定下一轮具体怎么练。** | 理解最好表现、主要问题和建议；按建议再练或完成 | 先展示 10–20 项指标、算法分数、不可执行的泛泛评价 |
| 统计 | **判断近期哪项在进步、哪项该复习。** | 看趋势、样本条件和状态；直达相关练习 | 单次练习明细、虚假精确的“掌握度百分比”、记录管理 |
| 设置 | **调整全局使用偏好。** | 管理主题、默认声音/显示、设备偏好（以正式能力为准） | 练习内容设置、训练计划、调试状态 |
| AI Coach | **针对当前练习获得一条可执行建议。** | 说明观察到的现象、证据边界和下一步；一键带入练习 | 聊天大厅、模型参数、提示词、无证据的教师式定论 |

## 页面之间的任务边界

```text
首页：选今天练什么
  ├─ 训练计划：确认今天的顺序
  ├─ 练习前：确认这一次怎么练
  ├─ 练习中：只练
  ├─ 结果：决定下一轮怎么练
  └─ 统计：回看一段时间的变化
```

## 页面级进入与离开条件

| 页面 | 进入时系统应已准备好 | 用户离开时应带走 |
|---|---|---|
| 首页 | 今日建议、可继续上下文、MIDI 简要状态 | 一个明确的练习意图 |
| 训练计划 | 今日任务及完成状态 | 选中的下一项任务 |
| 各基础练习前页 | 最近/推荐设置 | 本轮练习条件 |
| 曲谱练习前页 | 曲谱、片段、可用模式 | 曲目 + 片段 + 最少必要设置 |
| 练习中 | 已锁定的练习上下文 | 一组可解释的练习事件 |
| 结果 | 已保存记录、可观测证据 | 再练上下文，或完成状态 |
| 统计 | 聚合窗口与可比条件 | 要复习的能力/练习入口 |
| 设置 | 当前全局偏好 | 已保存的全局偏好 |
| AI Coach | 当前练习上下文与允许使用的证据 | 一条建议练习上下文 |

## 强制单任务检查

每页设计评审必须回答以下四问；任一回答为“否”则不进入正式 UI：

1. 用户能否在 5 秒内说出本页要做的一件事？
2. 页面是否只有一个视觉最强的主按钮？
3. 关闭所有二级/三级区域后，主任务是否仍可完成？
4. 页面是否避免要求用户理解系统架构、数据结构或算法置信度？
