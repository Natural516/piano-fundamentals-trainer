# F1 1366 × 768 原型说明

可运行原型位于 [`prototype/index.html`](prototype/index.html)。使用 URL hash 切换 6 个屏幕，所有屏幕都在 1366 × 768 首屏内完成主任务，不依赖纵向滚动。

## 屏幕地图

| Hash | 屏幕 | 唯一主任务 | 主按钮 |
|---|---|---|---|
| `#home` | 首页 | 开始今天最值得练的一项 | 开始今日训练 |
| `#score-pre` | 曲谱练习—练习前 | 确认片段后开始 | 开始练习 |
| `#score-focus` | 曲谱练习—专注模式 | 练这一段谱 | 暂停（停止为次动作） |
| `#result` | 练习结果 | 决定下一轮怎么练 | 按建议再练 |
| `#fundamentals` | 基础练习通用模板 | 确认本轮基础练习并开始 | 开始音阶练习 |
| `#plan` | 今日训练 / 训练计划 | 确认今天的练习顺序 | 开始下一项 |

## 交互串联

原型内主路径可点击：

```text
首页“开始今日训练” → 基础练习模板
首页“继续练习” → 曲谱练习前
曲谱练习前“开始练习” → 专注模式
专注模式“停止” → 结果页
结果页“按建议再练” → 曲谱练习前（已带建议条件）
结果页“完成” → 今日训练
```

## 1366 × 768 HUMAN QA 清单

- [ ] 6 个屏幕在 1366 × 768 不出现页面滚动条。
- [ ] 主按钮、MIDI 状态、当前练习条件均在首屏可见。
- [ ] 首页视觉优先级为：今日训练 > 继续上次 > 全部练习 > 近期状态。
- [ ] 曲谱练习前以乐谱和片段为主，不以设置面板为主。
- [ ] 专注模式没有正式侧栏、导入、AI 设置、片段管理或详细统计。
- [ ] 结果页不以正确率或错误数量作为第一信息。
- [ ] 1536 × 864 下内容只增加留白/乐谱面积，不放大控件密度。
- [ ] 所有演示按钮只切换静态原型屏幕，不写入数据、不调用 production。
